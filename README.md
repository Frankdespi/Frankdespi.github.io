# Frankdespi.github.io

Source for my portfolio site: [frankdespi.github.io](https://frankdespi.github.io).

It is a single static page (`index.html`) with no build step. The interactive demo on the page applies the routing rules from my capstone project, [reputation-feedback-intelligence-engine](https://github.com/Frankdespi/reputation-feedback-intelligence-engine). The demo uses preset scores and sample messages, not a live AI call.

## Projects

Each of these builds has its own repository:

- [Sales & Inventory Automation](https://github.com/Frankdespi/sales-inventory-automation): an n8n automation for a small juice business, in six lanes on one canvas.
- [My First AI Agent](https://github.com/Frankdespi/n8n-first-ai-agent): an n8n AI agent that searches the web, then messages and emails the answer.
- [Text to OpenAI API](https://github.com/Frankdespi/text-openai-): an n8n webhook workflow that validates a request, asks OpenAI to summarize and categorize the text, and replies with clean JSON.
- [Reputation & Feedback Intelligence Engine](https://github.com/Frankdespi/reputation-feedback-intelligence-engine): my TS Academy capstone.

The screenshots on the page live in the `assets` folder.
